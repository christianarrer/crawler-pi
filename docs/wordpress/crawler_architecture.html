3. TF2 coordinate frames

Dynamic transforms: the odometry node broadcasts odom → base_footprint. A localization or SLAM component may provide map → odom. Static transforms: base_footprint → base_link (z = 0.036 m), base_link → base_scan (x = −0.002854 m, z = 0.115 m, yaw = π), plus four cliff sensor frames. The IMU message uses imu_link; this launch file does not publish a corresponding static transform, so that frame must be defined separately if required by consumers.

5. Safety and implementation notes

The Pico cliff sensor stream is read by the motor driver, not by a separate ROS sensor node. The motor driver uses unknown or stale cliff information as a safety condition. The independent current guard monitors /battery/current and controls the motor-enable line. These mechanisms must be verified with the tracks lifted before deployment.

Tracked-vehicle kinematics: v_left = v_x − ω × track_width / 2 and v_right = v_x + ω × track_width / 2. The velocity target node converts each track speed into sprocket RPM and a calibrated motor duty fraction, with separate forward/reverse coefficients per motor.
