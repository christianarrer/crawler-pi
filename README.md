Crawler Pi

Crawler Pi is an open-source autonomous tracked robot project based on ROS 2 Jazzy.

The robot uses a Raspberry Pi 4B for low-level hardware control, sensor acquisition, motor control and safety monitoring. Computationally intensive tasks such as SLAM, localization, autonomous navigation and frontier-based exploration run on a separate Linux server.

The long-term goal is to enable the robot to autonomously explore its environment, navigate safely and return to a docking station for recharging.

The repository contains ROS 2 packages, configuration files, hardware designs and technical documentation.
